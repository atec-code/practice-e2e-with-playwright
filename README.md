# practice-e2e-with-plywright
This repository is a E2E testing playground with the testing framework playwright.  
You are free to download and try it out.

## How to setup
1. Clone the repository on your local machine
2. Run ```yarn install``` to initialize the project and install all dependencies
3. (Optional) Create a `.env` file to override defaults:
```
USERNAME=your_username
PASSWORD=your_password
BASE_API_URL=https://api.practicesoftwaretesting.com
```
4. Run ```yarn playwright test ```to run all the existing tests
